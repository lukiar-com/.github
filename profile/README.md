## Qué es Lukiar

Lukiar digitaliza la operación de restaurantes, peluquerías, gimnasios, retail, hoteles, productoras y más: punto de venta, cocina, agenda, tickets, menú y presencia digital, más una app pública para consumidores.

Modelo comercial claro: **Free forever**, **Trial Pro** y **Pro** por vertical — cuota fija, **0 % comisión** sobre las ventas del negocio.
